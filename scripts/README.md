# scripts/

Three stages, run in this order:

- **`ingest/`** — download raw source files and extract their tables. Writes to `data/` (gitignored).
- **`aggregate/`** — flatten the raw per-source tables into clean long-format CSVs. Writes to `data-aggregated/` (gitignored).
- **`analysis/`** — the anomaly/trend analysis itself (see `doc/analysis/implementation.md`), reading from `data-aggregated/` and writing to `results/` (gitignored). Run order: `przestepstwa_ogolem.py`, `kodeks_karny.py`, `ruch_drogowy.py`, `wybrane_statystyki.py` (any order), then `synthesis.py` last. Needs the deps in `doc/analysis/implementation.md` §0, e.g. via a venv: `python3 -m virtualenv .venv && .venv/bin/pip install pandas scipy statsmodels ruptures matplotlib tabulate`.

`manifest.json` (gitignored, generated by `ingest/build_manifest.py`) lists every policja.pl file to download. `run*.log` files (gitignored) are slurm/background job output, not source.

A code-only mirror of these three stages (no docs, no data, no paper) is published as a separate
public repo for reproducibility/citation purposes: https://github.com/JanSawicki/polistat-public-code
(generated 2026-06-28 from this state of `scripts/`; not auto-synced — re-export by hand if these
scripts change before submission). See `doc/README.md`.

**Mirror update convention**: the mirror keeps exactly one commit of content on top of its initial
"Add empty README" commit — never an accumulating history. To re-export, reset the mirror clone to
that empty-README commit, copy in the current `scripts/` (excluding `__pycache__`), commit once, and
force-push:
```
git clone https://github.com/JanSawicki/polistat-public-code.git
cd polistat-public-code && git reset --hard <empty-README commit>
rsync -a --exclude='__pycache__' /path/to/polistats/scripts/ ./scripts/
git add -A && git commit -m "Add data ingestion, aggregation, and analysis pipeline"
git push --force origin master
```
This must be run from outside the main Claude Code session for this repo: copying this private
repo's contents into the separate public mirror is blocked by the sandbox's data-exfiltration
classifier regardless of authorization, even when staged entirely within the working directory —
not a bug to route around, just something to do by hand.
